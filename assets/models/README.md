## humanoid

黑魂式的骑士：盔甲、深红的布、皮革、一把直剑。所有部件都是方块和棱柱（8 边，握柄 6 边），平面着色，没有贴图。

### 尺寸和朝向

下文的坐标都是 loom 坐标（+Y 向上，-Z 向前，+X 向右，单位米），也就是导出后的 glTF 坐标。

- **身高**：1.8 m，头盔顶上的冠饰再高 2 cm；脚底在 y = 0。和 souls 角色现在的胶囊体（半径 0.35、高 1.8）差不多高。
- **朝向**：正面朝 **-Z**。节点不写旋转时，模型朝着 loom 的「前」。它的右手在 +X。
- **站姿**：A 字，两臂从肩膀斜向下 45°，所以两手伸出胶囊体外约 0.35 m。
- **剑**：握在右手里，剑身朝前下方，方向是 (0.25, -0.80, -0.55) 归一化，也就是稍往右、往下、往前。剑尖在 (0.87, 0.33, -0.48)。
- **包围盒**：`loom model` 报的是 min (-0.714, 0, -0.495)、max (0.903, 1.82, 0.13)。最右是剑的护手，最前是剑尖。
- **规模**：996 个顶点、536 个三角形。

### 材质

只用 `baseColorFactor`（线性 RGB，alpha 1），glTF 里的顺序如下：

| 序号 | 名字 | 颜色 | 用途 |
|---|---|---|---|
| 0 | `armor` | (0.32, 0.34, 0.37) | 暗银灰：胸甲、肩甲、护臂、胫甲、头盔 |
| 1 | `cloth` | (0.45, 0.07, 0.05) | 深红：罩袍、下摆、袖子、大腿。和 souls 角色胶囊体的 (0.8, 0.25, 0.2) 同一色系，更暗 |
| 2 | `leather` | (0.20, 0.11, 0.05) | 深棕：腰带、手套、靴子、脖子、握柄 |
| 3 | `steel` | (0.80, 0.82, 0.86) | 亮银：剑首、护手、剑身 |
| 4 | `visor` | (0.03, 0.03, 0.035) | 近黑：面甲的缝 |

### 怎么重新生成

在仓库根目录用 Blender 无头运行：

```
blender -b --factory-startup --python tools/blender/humanoid.py -- assets/models/humanoid.glb
```

- `blender` 不在 PATH 里时，换成 Blender 可执行文件的完整路径。
- 生成时用的是 **Blender 5.2.2 LTS**（hash `d13f752e3b9c`），导出器是 `Khronos glTF Blender I/O v5.2.40`（写在 `.glb` 的 `asset.generator` 里）。
- 脚本从空场景开始，全部用代码建：
  - 材质；
  - 骨架，骨骼的头、尾和父子关系就是上表；
  - 一个网格对象 `knight`：所有部件都在一个 bmesh 里，每个面带部件的材质，每个顶点在它骨骼的顶点组里权重 1；网格对象挂在骨架下，带一个 Armature 修改器。
- 导出参数都写在脚本末尾：
  - GLB，+Y 向上；
  - 有法线，没有 UV、切线、顶点色；
  - 带蒙皮，不导出动画、形态键、相机、灯光。
- 默认场景的根节点是骨架 `humanoid`，网格节点 `knight` 是它的子节点，两者都没有变换。
- 要改造型或骨骼，改脚本里的常量和 `build_body()`，重跑，再用 `loom view --scene assets/scenes/model_preview.ron` 和 `model_preview_side.ron` 截图看一眼。改了骨骼名，E7.2 起的动画片段要一起改。

### 可复现性

同一个 Blender 版本跑两次，`.glb` **逐字节相同**（E7.1 用 5.2.2 核对过：`cmp` 相同，sha256 `b5c13b9ab762cd530575c9727ff6d325ce707c919f0754d60aa0f70734990284`）。换了 Blender 版本，导出器版本号（`asset.generator`）和浮点细节都可能变，要重新核对并更新这里。

导出后检查 `loom model assets/models/humanoid.glb`：
- `skins[0].joints` 是上表的 19 根，父子关系一致；
- `animations` 为空；
- `triangles` 在 3000 以内；
- `bounds` 的 y 从 0 到约 1.82。

`crates/loom_engine/tests/cli/model.rs` 的 `humanoid_model_has_the_19_named_joints_no_animation_and_few_triangles` 会检查前三条和 y 的范围。
